# Data privacy and security

The original Seva Guest Visit export contains personal information. Do **not** commit it to GitHub.

This repository intentionally ignores `data/*`, fitted `.joblib` models, and recipient-level prediction exports. The included `sample_data/` file is synthetic and contains no real recipients.

Before sharing any output publicly, verify that it contains only aggregate statistics and no Guest IDs, names, addresses, dates of birth, or other identifying fields.
